# Engineer Hiring Exercises

Take-home exercises for engineering candidates.

## Layout

- `engineer-1/`, `engineer-2/` — exercise instructions per role, each with `py/` and `node/` variants.
- `roles/` — role descriptions.
- `prompts/` — AI chat logs submitted with a candidate's work.
- `scripts/` — helper scripts (e.g. `sync_prompts.py` copies Claude Code chat logs into `prompts/`).
